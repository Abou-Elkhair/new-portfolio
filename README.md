# Abouelkhair Rady — UI/UX Portfolio

A static portfolio site featuring six product case studies and an animated gallery of selected product screens.

## Run locally

Serve the `dist` directory with any static web server. For example:

```sh
python3 -m http.server 8000 --directory dist
```

Then open `http://localhost:8000`.

## Project structure

- `dist/index.html` — portfolio homepage and case studies
- `dist/*.css` — styles and responsive layouts
- `dist/script.js` — navigation and gallery interactions
- `dist/images/` — original project screen exports and case-study visuals
